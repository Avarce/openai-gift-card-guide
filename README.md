## OpenAI Gift Card 是什么

一张美元储值卡，兑换后变成你 ChatGPT 账号里的 Wallet 余额。它不是银行卡，也不是直接开通一个月会员的兑换码。

</p>
<p align="center"><sub>图 1：礼品卡条款站展示的 OpenAI ChatGPT Gift Card 卡面设计。</sub></p>

钱是这样走的：

~~~mermaid
flowchart LR
    A[参与计划的零售商] --> B[OpenAI Gift Card PIN]
    B --> C[chatgpt.com/redeem]
    C --> D[ChatGPT Wallet 美元余额]
    D --> E[ChatGPT 网页端购买或续费]
~~~

几条容易踩坑的规则，出自 2026 年 9 月 1 日生效的[礼品卡条款](https://mycardterms.com/openai/home/terms/)：

| 项目 | 规则 |
| --- | --- |
| 面额 | 单张通常 $15–$250，具体看零售商；单人每天购卡合计不超过 $2,000 |
| 能不能再充 | 卡本身不能再充值；同一账号可以兑换多张，但受账户余额和每日加载上限限制 |
| 会不会过期 | 条款不设到期日，也不收余额管理费；长期不用时仍可能适用美国各州的无主财产规则 |
| 能不能退、能不能卖 | 一般不能退款、不能换现金、不能有偿转售；可以免费送人 |
| 兑换之后 | 全部金额一次进账，不能拆分，不能转到别的账号，也不能退回原卡 |
| 谁发的卡 | 发卡方是 CIMI2604, Inc.，不是 OpenAI 本身 |

## 如何用 Wallet 开通 Plus 或 Pro

1. 用同一个账号在网页端打开升级页面，选套餐。
2. 在结账页看清价格、税费、Wallet applied 和 Due today。
3. 余额不够，差额用其他付款方式补。余额够的话，部分结账可以不加付款方式，但试用、促销等情况仍可能要求绑卡。
4. 买完检查当前套餐、下次续费日和剩余余额。

Plus 标价 $20 / 月，但加上税费可能更高，别刚好按 $20 买卡。Wallet 会自动优先抵扣，没法指定只用一部分。如果人去了美国以外的地方，美元余额付不了按其他币种计费的账单。

## Wallet、usage credits 和 Gifting Credits 的区别

| 名称 | 是什么 | 用来干什么 |
| --- | --- | --- |
| OpenAI Gift Card | 在官方兑换页用的 PIN | 兑换后增加 Wallet 美元余额 |
| ChatGPT Wallet | 账号里的美元余额 | 支付网页端的订阅、续费和额度购买 |
| 使用额度（usage credits） | Work、Codex 等功能的用量 | 需要单独购买，可以用 Wallet 付 |
| Gifting Credits | 送给别人的一次性领取链接 | 领取后增加对方的使用额度，不是 Wallet 余额 |

**往 Wallet 充钱，不等于买好了 Codex / Work 的使用额度**，额度要另外买。Gifting Credits 的领取链接要在购买后 30 天内使用，领取后的额度 12 个月有效，规则跟礼品卡不一样。来源：[Wallet 说明](https://help.openai.com/en/articles/20001508-using-your-chatgpt-wallet-balance) · [Gifting Credits](https://help.openai.com/en/articles/20001417-gifting-credits-in-chatgpt)

## 余额和结账出问题怎么查

先到持有余额的账号打开 **Settings → Billing**，对着交易记录看：

| 看到的情况 | 先查什么 |
| --- | --- |
| `Loading balance…` 或 `Not available` | 余额暂时没显示，不等于是零。刷新后看交易记录，别为了测试再买一张 |
| 兑换记录有了，账号还是 Free | 兑换和买套餐是两步，看看是不是还没结账 |
| 有余额，但结账没抵扣 | 核对账号、工作区、USD 币种和购买资格，再看 Wallet applied 和 Due today |
| 余额比卡面少 | 先查有没有待付款项、购买记录和账单调整 |
| 收据应付 $0 | 可能是 Wallet 付清了，不是套餐免费 |
| PIN 没输错，却兑换不了，账号用的是赠送的订阅 | 帮助页说明，部分赠送订阅不能兑换，即使套餐名在支持列表里。联系 OpenAI Support |

**退款：** 已兑换的余额不能退回原卡；用余额买的 ChatGPT 项目获批退款时，Wallet 付的那部分退回 Wallet。个人余额和 Business 工作区余额分开管理。

**怀疑卡被别人兑换了：** 联系 OpenAI Support，提供账号邮箱、礼品卡的序列号（serial number，不是 PIN）、报错原文和发生时间（带时区）。PIN 不要发到公开的地方。

## 别买错：官方卡和第三方「ChatGPT 礼品卡」

官方卡有三个特征：在参与计划的零售商买；明确写着兑换成 ChatGPT Wallet 余额；PIN 直接在 [chatgpt.com/redeem](https://chatgpt.com/redeem) 兑换。条款也提醒，从未经授权的卖家、转售商或拍卖网站拿到的卡可能无效。

> [!CAUTION]
> 搜「ChatGPT Gift Card」会看到 Rewarble 这类第三方 voucher：先在它的网站兑换，生成带卡号、有效期和 CVV 的 Reward Card，再当银行卡填进 ChatGPT 收银台。它不是 OpenAI 的官方礼品卡，Rewarble 自己也说明与所展示品牌无关联。[Rewarble 页面](https://rewarble.com/brands/chatgpt)

只凭商品名里有 ChatGPT、页面有 ChatGPT Logo，不能说明它是官方卡。

### 用美国节点能不能兑换？

- **官方规定：** 兑换时要人在美国、账号按美元计费。OpenAI 帮助页把“人不在美国或账号不是美元计费”列为兑换失败的常见原因。
- **实际情况：** 很多国内用户本来就是挂美国节点用 ChatGPT。OpenAI 没公开怎么判断“人在美国”，所以挂着稳定的美国节点、账号又是美元计费时，兑换**有可能**通过。但这不在官方规则之内，截至 9 月 23 日我们还没看到可靠的公开实测，成功或失败都说不准。
- **真正的风险在钱：** 兑换失败的话，卡就砸在手里了。Best Buy 和 BJ’s 的礼品卡都不退款，也不能换现金，只能免费送给人在美国的人。
- **真想试：** 先买最小面额（Best Buy 的 $25）；兑换和之后结账都用平时那个稳定的美国节点，别中途换地区；Best Buy 的付款信息如实填写，别编造账单地址。试完不管成没成，欢迎提 Issue 告诉大家。

## 常见问题

<details>
<summary><strong>OpenAI Gift Card 现在能买到吗？</strong></summary>

能，在美国。本文收录了 Best Buy、BJ’s 和 RaiseRight 三个渠道，OpenAI 帮助页也点名了 Best Buy。面额、价格和门槛见[购买渠道对照](#现在在哪里购买)。

</details>

<details>
<summary><strong>人在中国大陆，可以买来给自己的 ChatGPT 充值吗？</strong></summary>

官方规则是不行：购买和兑换都只限美国，兑换时要人在美国、账号按美元计费。挂美国节点有可能通过兑换页的地区判断，但官方没说怎么判断，我们也还没看到可靠实测；失败的话卡不能退。真想试，先买 $25 的小面额，详见[用美国节点能不能兑换](#用美国节点能不能兑换)。

</details>

<details>
<summary><strong>Best Buy 能用国内银联卡买吗？</strong></summary>

结账页有银联标识，但国内发行的银联卡不一定能通过，要看银行授权和订单审核。详见[结账截图与付款说明](#best-buy-结账截图)。

</details>

<details>
<summary><strong>Best Buy 显示付了款，为什么还没收到卡？</strong></summary>

银行预授权不等于已经发卡。先看订单详情、邮箱和垃圾邮件，按邮件提示处理；超过预计交付时间还没收到，联系 Best Buy 客服。

</details>

<details>
<summary><strong>兑换礼品卡后会自动变成 Plus 吗？</strong></summary>

不会。兑换只把钱充进 ChatGPT Wallet，还要在网页端选 Plus 并完成结账。

</details>

<details>
<summary><strong>有礼品卡就不用绑银行卡了吗？</strong></summary>

不一定。余额够的时候，部分结账可以不加付款方式，但不是所有结账都行；试用、促销、余额不足时仍可能要求绑卡。

</details>

<details>
<summary><strong>礼品卡能付 OpenAI API 吗？</strong></summary>

不能。ChatGPT Wallet 和 OpenAI API 的账单是两套系统。

</details>

<details>
<summary><strong>礼品卡会过期吗？</strong></summary>

2026 年 9 月 1 日版条款不设到期日，也不收余额管理费；但长期不用时，余额仍可能按美国各州的无主财产法律处理，所以不能简单说“永久有效”。

</details>

<details>
<summary><strong>同一个账号能兑换多张吗？</strong></summary>

可以，但受账户余额、每日加载和安全限制；单人每天购卡合计也不能超过 $2,000。

</details>

<details>
<summary><strong>兑换错了账号能转过去吗？</strong></summary>

不能。兑换前一定核对账号和工作区。

</details>

<details>
<summary><strong>现在用 App Store / Google Play 订阅的，能改用 Wallet 续费吗？</strong></summary>

不能直接抵扣。官方的做法是：先在原来的商店（App Store 或 Google Play）取消订阅，等这一期到期结束，再用同一个 ChatGPT 账号在网页端订阅。兑换礼品卡不会取消现有的订阅。

</details>

<details>
<summary><strong>没收到卡，或者 PIN 兑换不了，该找谁？</strong></summary>

购买、付款、邮件送达、卡片激活和退款找零售商；PIN 兑换、Wallet 和 ChatGPT 结账的问题找 OpenAI Support。

</details>
